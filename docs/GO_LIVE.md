# Go Live: Neon + Render + Vercel + GitHub

Total time: about 15 minutes. All three services have a free tier.

```
 Phone / Browser  ──►  Vercel (Next.js website + installable app)
                          │  NEXT_PUBLIC_API_URL
                          ▼
                       Render (FastAPI API)  ──►  Neon (PostgreSQL)
```

**Use the Singapore region everywhere** (closest to Bangladesh, lowest latency).

---

## Step 1: Neon (database)

1. [neon.tech](https://neon.tech) → **Create project** → name `bizmind-bd`, region **AWS Asia Pacific (Singapore)**.
2. Click **Connect**. **Turn OFF the "Connection pooling" toggle** (use the direct connection).
3. Copy the connection string. It looks like:
   `postgresql://neondb_owner:xxxx@ep-xxxx.ap-southeast-1.aws.neon.tech/neondb?sslmode=require`
   Paste it as-is. The app converts it automatically.

## Step 2: GitHub (push the code)

Unzip the project, then in that folder:

```bash
git init
git add .
git commit -m "BizMind BD: ready for Neon + Render + Vercel"
git branch -M main
git remote add origin https://github.com/<your-username>/bizmind-bd.git   # create an empty repo first
git push -u origin main
```

`.gitignore` already keeps `.env` files and `node_modules` out of the repo.

## Step 3: Render (API)

1. [render.com](https://render.com) → **New +** → **Blueprint** → connect GitHub → select the repo.
   Render reads `render.yaml` and creates `bizmind-bd-api`.
2. When asked for values, fill in:
   - `DATABASE_URL` = the Neon string from Step 1
   - `CORS_ORIGINS` = `https://placeholder.vercel.app` (you'll fix this in Step 5)
   - `AI_API_KEY` = leave empty (the AI assistant works without it, in built-in mode)
3. **Apply**. Wait until the deploy shows **Live**. Database tables are created automatically on first start (Alembic migrations).
4. Copy your API URL, e.g. `https://bizmind-bd-api.onrender.com`.
5. Check it: open `https://bizmind-bd-api.onrender.com/api/health`. You should see `{"status":"ok"}`.
   (Interactive API docs are at `/docs`.)

## Step 4: Vercel (website + app)

1. [vercel.com](https://vercel.com) → **Add New… → Project** → import the same GitHub repo.
2. **Root Directory → `frontend`** (important). The framework is auto-detected as Next.js.
3. **Environment Variables** → add:
   - `NEXT_PUBLIC_API_URL` = your Render URL from Step 3 (no trailing slash)
4. **Deploy**. You'll get a URL like `https://bizmind-bd.vercel.app`.

## Step 5: Connect them (CORS)

Back in Render → your service → **Environment**:

- Set `CORS_ORIGINS` = your exact Vercel URL, e.g. `https://bizmind-bd.vercel.app` (no trailing slash)
- (Optional) set `CORS_ORIGIN_REGEX` = `https://bizmind-bd.*\.vercel\.app` to also allow Vercel preview deployments.

Save. Render redeploys automatically. Then open your Vercel URL and **Register**. The first user of a business becomes its Owner.

## Step 6 (optional): Demo data

To fill the app with realistic sample data, run this once **from your computer** (needs Python):

```bash
cd backend
pip install -r requirements.txt
DATABASE_URL="<your Neon string>" python ../database/seed/seed.py
```

Logins: `owner@demo.bd` / `manager@demo.bd`, password `Demo@1234`.
**Warning:** that password is in the public README, so on a real public site, skip seeding or change the passwords afterward.

## Step 7: Use it as an app

- **Android (Chrome):** open the Vercel URL → menu → **Install app**.
- **iPhone (Safari):** open the URL → **Share** → **Add to Home Screen**.

## Free-tier things to know

| Service | Behavior | Fix |
|---|---|---|
| Render free | API sleeps after 15 min idle; the first request takes ~30-60 s | Upgrade to Starter (~$7/mo), or ping `/api/health` every 5-10 min with a free monitor such as UptimeRobot |
| Neon free | Database auto-suspends when idle; first query adds ~1 s | Already handled (`pool_pre_ping`, `pool_recycle`) |

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| "Can't reach the server" on login | `NEXT_PUBLIC_API_URL` is wrong, or the Render API is still waking up. Wait 60 s and retry |
| Browser console shows a CORS error | `CORS_ORIGINS` doesn't exactly match your Vercel URL (check `https://`, no trailing `/`) |
| Changed `NEXT_PUBLIC_API_URL` but nothing changed | It's baked in at build time. In Vercel → **Deployments → Redeploy** |
| Render deploy fails at `alembic` | `DATABASE_URL` is wrong or missing. Re-copy it from Neon |
| 500 errors | Render → **Logs** shows the real traceback |
| Want AI answers from Claude | Set `AI_PROVIDER=anthropic`, `AI_API_KEY=<key>`, `AI_MODEL=<model name>` on Render |

## Security checklist

- `JWT_SECRET` is auto-generated by Render and never in the repo.
- Never commit `.env` files or your Neon connection string.
- Don't seed demo accounts on a site with real business data.
