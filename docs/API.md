# API

Base URL: `http://localhost:8000` (dev). All endpoints except `/api/auth/register`,
`/api/auth/login` and `/api/health` require `Authorization: Bearer <token>`.
Interactive docs: `GET /docs` (Swagger UI, auto-generated by FastAPI from the code below —
always current).

## Auth
```
POST   /api/auth/register        {business_name, email, password, full_name, job_title?}
POST   /api/auth/login           {email, password}
GET    /api/auth/me
```

## Products
```
GET    /api/products             ?search=&category_id=&status=&page=&page_size=
POST   /api/products
GET    /api/products/{id}
PUT    /api/products/{id}
DELETE /api/products/{id}        archives (soft delete) — owner or manager
GET    /api/products/meta/categories
POST   /api/products/meta/categories
```

## Inventory
```
GET    /api/inventory
GET    /api/inventory/alerts
POST   /api/inventory/adjust     {product_id, type: stock_in|stock_out|adjustment, direction?, quantity, reason?}
GET    /api/inventory/{product_id}/history
```

## Sales
```
GET    /api/sales                ?customer_id=&product_id=&date_from=&date_to=&page=&page_size=
POST   /api/sales                {customer_id?, payment_method, items:[{product_id, quantity}]}
GET    /api/sales/summary        ?days=
GET    /api/sales/{id}
POST   /api/sales/{id}/cancel    restores stock through the same ledger
```

## Customers
```
GET    /api/customers            includes computed total_spent/total_orders/segment
POST   /api/customers
GET    /api/customers/{id}
```

## Suppliers
```
GET    /api/suppliers
POST   /api/suppliers
GET    /api/suppliers/{id}
GET    /api/suppliers/compare    ?product_id=   (price, delivery, reliability, quality, fulfillment — not one score)
PUT    /api/suppliers/{id}/prices {product_id, price, minimum_order_quantity}
```

## Procurement
```
GET    /api/purchase-orders
POST   /api/purchase-orders      creates a DRAFT
GET    /api/purchase-orders/{id}
PUT    /api/purchase-orders/{id}/status   {status}  — enforces the allowed state machine
POST   /api/purchase-orders/{id}/approve  owner-only; draft's status must be pending_approval
```

## Administration (owner-only)
```
GET    /api/employees
POST   /api/employees
GET    /api/audit-logs           ?page=&page_size=
GET    /api/settings
PUT    /api/settings/business    {name?, industry?, address?}
```

## Errors

All errors return `{"detail": "..."}` in plain language — never a stack trace or raw
database message (§36). Validation errors (422) name the specific field, e.g.
`"Invalid input: sku is required."`
